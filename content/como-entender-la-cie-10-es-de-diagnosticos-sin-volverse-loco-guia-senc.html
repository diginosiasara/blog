La CIE-10-ES es el sistema que se utiliza para codificar diagnósticos en el ámbito sanitario en España. A primera vista puede parecer complicada, llena de códigos, reglas y símbolos. Sin embargo, si se entiende su estructura básica, resulta mucho más fácil utilizarla correctamente.

En este artículo explico de forma sencilla los conceptos fundamentales que todo estudiante o profesional sanitario debería conocer.

1️⃣ Dos partes fundamentales: dónde buscar y dónde confirmar

La CIE-10-ES tiene dos partes principales que siempre se utilizan juntas:

Índice Alfabético de Enfermedades (IAE) Se utiliza para buscar el diagnóstico. Es el primer paso cuando queremos encontrar un código.

Lista Tabular (LT) Se utiliza para confirmar el código correcto y revisar instrucciones adicionales.

Una forma fácil de recordarlo es esta frase:

“Índice para buscar, Lista Tabular para confirmar.”

Nunca se debe asignar un código solo con el Índice Alfabético.

2️⃣ El término principal: la clave de la búsqueda

En el Índice Alfabético, el elemento más importante es el término principal, que aparece escrito en negrita.

Normalmente corresponde al nombre de la enfermedad, por ejemplo:

  • Faringitis

  • Diabetes

  • Hernia

Sin embargo, a veces el término principal puede ser:

  • un síntoma (dolor, debilidad)

  • un epónimo, es decir, una enfermedad que lleva el nombre de una persona (como enfermedad de Crohn)

Debajo del término principal aparecen los modificadores, que ayudan a especificar el diagnóstico.

3️⃣ Modificadores esenciales y no esenciales

Los modificadores añaden información al término principal.

Modificadores esenciales Son necesarios para encontrar el código correcto. Cambian el código.

Modificadores no esenciales Aparecen entre paréntesis y no cambian el código.

Comprender esta diferencia es importante para evitar errores al codificar.

4️⃣ La jerarquía de los códigos

La Lista Tabular organiza los diagnósticos en una estructura jerárquica. Esto significa que los códigos se ordenan de lo más general a lo más específico.

La estructura es la siguiente:

Capítulo → Sección → Categoría → Subcategoría → Código final

Algunos detalles importantes:

  • Las categorías tienen 3 caracteres

  • Las subcategorías tienen 4 o 5 caracteres

  • El código final puede llegar hasta 7 caracteres

Esta organización permite describir los diagnósticos con mayor precisión.

5️⃣ El séptimo carácter y el marcador “X”

Uno de los aspectos que más dudas genera es el séptimo carácter.

En algunos códigos, la clasificación exige un séptimo carácter para indicar información adicional, como:

  • tipo de contacto asistencial

  • fase del tratamiento

  • secuelas

El problema es que a veces el código base no tiene suficientes posiciones para llegar al séptimo carácter.

En ese caso se utiliza la letra “X” como marcador de posición para completar los espacios.

Este recurso permite mantener la estructura del código sin perder información.

6️⃣ Convenciones importantes que aparecen en la clasificación

La CIE-10 utiliza diferentes símbolos e indicaciones que ayudan a interpretar correctamente los códigos.

Por ejemplo:

Paréntesis ( ) Indican modificadores no esenciales.

Corchetes [ ] Se utilizan para mostrar sinónimos o códigos de manifestación.

Excluye 1 Significa que el diagnóstico no debe codificarse en esa categoría.

Excluye 2 Indica que los diagnósticos pueden coexistir, por lo que ambos códigos pueden utilizarse.

Distinguir entre estas dos indicaciones es clave en la codificación clínica.

7️⃣ Etiología y manifestación: el orden correcto

En algunos casos, un diagnóstico describe la manifestación de una enfermedad, pero no la enfermedad principal.

Estos códigos se llaman códigos de manifestación.

Sus características son:

  • aparecen en cursiva en la Lista Tabular

  • no pueden ser diagnóstico principal

Por eso, la regla de codificación es clara:

1️⃣ Primero se codifica la enfermedad de base (etiología) 2️⃣ Después se codifica la manifestación

Este orden permite reflejar correctamente la relación entre enfermedades.

Conclusión

Aunque la CIE-10-ES puede parecer compleja al principio, entender algunos conceptos básicos facilita mucho su uso.

Los puntos clave son:

  • usar el Índice Alfabético para buscar

  • confirmar siempre en la Lista Tabular

  • identificar el término principal

  • comprender la estructura jerárquica de los códigos

  • saber cuándo usar el marcador X

  • diferenciar Excluye 1 y Excluye 2

Con práctica y familiaridad con el sistema, la codificación diagnóstica se vuelve un proceso mucho más claro y sistemático.

Si trabajas o estudias en el ámbito sanitario, dominar estas bases te ayudará a interpretar y utilizar correctamente la clasificación CIE-10-ES en tu práctica diaria.
